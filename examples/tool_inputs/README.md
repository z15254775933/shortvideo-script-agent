# 第三步工具夹具

此目录中的脚本均为开发阶段预先构造、由 AI 助手编写的工具测试输入，不是业务 Agent 在线自主生成的结果，也不证明提交者手写了初稿或 Agent 会修改脚本。AI 使用范围见 `docs/04-ai-usage.md`。

- `overlong.json`：保留较长文案和画面占用预算，自报总时长故意填写为 1 秒，用来检查估时工具是否重新计算。
- `within_budget.json`：独立提供的短版本夹具，修订号为 2，文案和画面占用均有变化。不能将它与长版本并列视作真实模型压缩记录。
- `unsupported_claim.json`：合法引用 P01 的“支持字幕”，但在旁白和字幕额外添加无依据的全角数字宣传，用来检查引用之外的内容也会被拦截。

对应实际输出由 CLI 写入 `examples/phase03/`。这里的产品和品牌资料均为合成内容；已知事实只有素材列出的两项能力。
